ITSaNAS Set up this machine

    Welcome

    ITSaNAS keeps one folder the same on all your machines. Your files are locked with a key only you have, and copies are kept on other members' computers in case yours breaks.

    This takes about five minutes. Each step is saved: if something stops, run setup again and it picks up where it left off.

    Account

    Your secret

    Never type your recovery words into a web page — not even this one.

    Your secret is asked in a separate ITSaNAS window, never on this page.

    • A new account gets 24 recovery words. Write them on paper: they are the only way back into your files if this machine is lost. The window then asks three of them back.
    • An existing account: the window asks for your 24 words, unless your coordinator keeps your recovery copy.
    • Then the window asks for a passphrase that unlocks this machine.

    The window opens when you press Start setting up, after the next few questions.

    Joining the network

    Type the coordinator address you were given with your invitation.

    Leave empty if all your machines are on the same home network.

    Space you offer

    Choose how much of this disk other members may use for their copies.

    Offering space is what earns room for your own files on theirs. You can change it later.

    Your folder

    Choose the folder to keep the same on all your machines.

    It is created if it does not exist. Files you put in it are synced.

    Ready

    Press Start. ITSaNAS then checks the connection, starts in the background and checks that it all works.
